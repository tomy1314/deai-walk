# 禁词表（合并版）​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

> 本表是**通用 AI 味词表**（一级/二级/三级 + 句式），用于通用分支与叙事分支的诊断。
> 与创作 skill（百万字小说生成）的 `banned_words.md` 不合并：创作 skill 的表管"这本书不能出现的项目级禁词"，本表管"AI 味词的通用分级"。
> 冲突时项目级禁词优先（见 `adjudication.md` 第 12 条）。本表的"二级每篇最多1次"只用于独立诊断，不用于创作 skill 出稿门槛。

本表为唯一权威词表；anti_ai_words.md 与 ai_taste_scanner.py 向本表对齐。

写作和改写时严格控制以下词汇频率。一级绝对禁止，二级每篇最多1次，三级注意分布。

## 一级禁词（绝对禁止）​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

| 禁词 | 替代方案 |
|------|---------|
| 不禁 | 【删】直接写动作 |
| 宛如 | 【换词】像、跟……似的 |
| 犹如 | 【换词】像、好比 |
| 仿佛 | 【换词】用比喻替代，或直接描写 |
| 恍若 | 【换词】像、似乎 |
| 宛若 | 【换词】像 |
| 恍如 | 【换词】像 |
| 恰似 | 【换词】像 |

> 宛如/犹如/仿佛/恍若/宛若/恍如/恰似：优先【换词】，写不出就【具体化】写比喻。

## 二级禁词（每篇最多1次）​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

| 禁词 | 替代方案 |
|------|---------|
| 不由得 | 【动作化】直接写动作/反应 |
| 默默地 | 【动作化】低头、背过身、攥紧拳头 |
| 缓缓地 | 【删】或【具体化】找更具体的速度描述，或直接删 |
| 渐渐地 | 【具体化】用变化本身替代：天暗了、声音远了 |
| 淡淡地 | 【动作化】用神态细节替代：嘴角一勾、眼皮都没抬 |
| 深深地 | 【删】或【动作化】直接写感受或动作 |
| 轻轻地 | 【具体化】指尖碰了一下、几乎听不见地 |
| 凝视 | 【换词】或【动作化】盯着看、目光落在……上 |
| 注视 | 【换词】或【动作化】看着、盯着 |
| 仰望 | 【换词】或【动作化】抬头看 |
| 眺望 | 【换词】或【动作化】看向远处 |
| 环顾 | 【换词】或【动作化】扫了一眼 |
| 凝望 | 【换词】或【动作化】看着 |
| 驻足 | 【换词】或【动作化】停下、站住了 |
| 凝滞 | 【换词】僵住、顿住、停了一下、卡了一下 |
| 静谧 | 【换词】安静、静、没声音 |

## 三级警惕词（注意分布，一段内不重复出现）​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

| 词汇 | 问题 | 建议 |
|------|------|------|
| 在……之中 | 句式套路化 | 【删】改为直接陈述 |
| 随着…… | 万能开头 | 【删】换起句方式 |
| 此刻 | 过度使用 | 【动作化】直接切入场景 |
| 内心深处 | 空洞 | 【动作化】用行为暗示内心 |
| 一种……的感觉 | 模糊 | 【具体化】具体化这个感觉 |
| 不由自主 | 套话 | 【动作化】写具体反应 |
| 油然而生 | 文言腔 | 【动作化】日常化表达 |
| 莫名其妙 | 滥用 | 【具体化】说出具体哪里奇怪 |
| 若有所思 | 空洞 | 【具体化】写出思考的具体内容或表情 |
| 心头一紧/一颤/一暖 | 批量生产感 | 【动作化】换更独特的身体反应 |
| 嘴角上扬 | 偶像剧感 | 【动作化】写更自然的笑法 |
| 空气中弥漫着 | 套话 | 【具体化】具体写出什么味道 |
| 时间仿佛静止 | 被用烂了 | 【具体化】换表达 |
| 指尖 | 虚假细腻感 | 【换词】手指、指节、手 |
| 闷闷的/闷声 | 情绪掩饰词 | 【具体化】直接写声音状态：压低声音、含糊地应了一声 |
| 薄薄的/薄 | 强行文艺 | 【具体化】写具体：光、雾、汗，不要用'薄'敷衍。脚本仅检测「薄薄」子串；单字「薄」由人工按语境判断（纯客观描述如"薄雾""薄饼"保留，强行文艺渲染如"薄的悲伤""薄薄一层凉意"才替换）。 |
| 堆满/堆着/堆砌 | 空间感匮乏 | 【换词】散落、摞着、漫出来、排满 |
| 周到 | 完美机器感 | 【删】删掉形容词，直接写他具体做了什么（如：提前调好了空调） |
| 语气平平 | 语气平淡 | 【换词】不咸不淡、淡得听不出起伏、听不出情绪（搭配限制：仅"语气/声音+平平"） |

高频才替换观察项（不预禁，同一文本出现 3 次以上再处理）：一层层、恰到好处。

## AI 高频词（能删就删，统一【删】）​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

此外【删】、至关重要【删】、深入探讨【删】、强调【删】、持久的【删】、增强【删】、培养【删】、获得【删】、突出【删】、相互作用【删】、复杂/复杂性【删】、格局（抽象名词）【删】、关键性的【删】、展示【删】、织锦（抽象名词）【删】、证明【删】、宝贵的【删】、充满活力的【删】

## 句式黑名单​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

1. **"他/她不禁+动作+，+内心独白"** → 直接写动作
2. **"在月光/阳光/灯光下，他/她的脸/身影+形容词"** → 换角度写
3. **"此时此刻，他/她终于明白……"** → 用行为展现
4. **"空气中弥漫着……的气息"** → 具体写出什么味道
5. **"时间仿佛静止了"** → 换表达
6. **"一阵寒意/暖意涌上心头"** → 写具体身体反应
7. **排比三连以上** → 最多两个，第三个必须打破
8. **每段结尾升华/总结** → 自然结束
