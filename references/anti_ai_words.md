# AI味高频词黑名单​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

本表与 banned_words.md 同步；banned_words.md 为权威源，冲突时以它为准。

写作时严格控制以下词汇的出现频率。全文每种词最多出现1次，能不用就不用。

## 一级禁词（绝对禁止，出现即AI味极重）​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

| 禁词 | 替代方案 |
|------|---------|
| 不禁 | 直接写动作 |
| 宛如 | 像、跟……似的 |
| 犹如 | 像、好比 |
| 仿佛 | 用比喻替代，或直接描写 |
| 恍若 | 像、似乎 |
| 宛若 | 像 |
| 恍如 | 像 |
| 恰似 | 像 |

## 二级禁词（严格控制，每篇最多1次）​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

| 禁词 | 替代方案 |
|------|---------|
| 不由得 | 直接写动作/反应 |
| 默默地 | 低头、背过身、攥紧拳头 |
| 缓缓地 | 找更具体的速度描述，或直接删 |
| 渐渐地 | 用变化本身替代：天暗了、声音远了 |
| 淡淡地 | 用神态细节替代：嘴角一勾、眼皮都没抬 |
| 深深地 | 直接写感受或动作 |
| 轻轻地 | 指尖碰了一下、几乎听不见地 |
| 凝视 | 盯着看、目光落在……上 |
| 注视 | 看着、盯着 |
| 仰望 | 抬头看 |
| 眺望 | 看向远处 |
| 环顾 | 扫了一眼 |
| 凝望 | 看着 |
| 驻足 | 停下、站住了 |

## 三级警惕词（高频即AI味，注意分布）​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

| 词汇 | 问题 | 建议 |
|------|------|------|
| 在……之中 | 句式套路化 | 改为直接陈述 |
| 随着…… | 万能开头 | 换起句方式 |
| 此刻 | 过度使用 | 直接切入场景 |
| 内心深处 | 空洞 | 用行为暗示内心 |
| 一种……的感觉 | 模糊 | 具体化这个感觉 |
| 不由自主 | 套话 | 写具体反应 |
| 油然而生 | 文言腔 | 日常化表达 |
| 莫名其妙 | 滥用 | 说出具体哪里奇怪 |
| 若有所思 | 空洞 | 写出思考的具体内容或表情 |
| 心头一紧/一颤/一暖 | 批量生产感 | 换更独特的身体反应 |
| 嘴角上扬 | 偶像剧感 | 写更自然的笑法 |
| 空气中弥漫着 | 套话 | 具体写出什么味道（与下方句式黑名单第4条重复，检测时合并计一次） |
| 时间仿佛静止 | 被用烂了 | 换表达（与下方句式黑名单第5条重复，检测时合并计一次） |
| 指尖 | 虚假细腻感 | 手指、指节、手 |
| 闷闷的/闷声 | 情绪掩饰词 | 直接写声音状态：压低声音、含糊地应了一声 |
| 薄薄的/薄 | 强行文艺 | 写具体：光、雾、汗，不要用"薄"敷衍。脚本仅检测「薄薄」子串；单字「薄」由人工按语境判断（纯客观描述如"薄雾""薄饼"保留，强行文艺渲染如"薄的悲伤""薄薄一层凉意"才替换）。 |
| 堆满/堆着/堆砌 | 空间感匮乏 | 散落、摞着、漫出来、排满 |
| 周到 | 完美机器感 | 删掉形容词，直接写他具体做了什么（如：提前调好了空调） |

## 句式黑名单​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

以下句式结构AI味极重，必须避免：

1. **"他/她不禁+动作+，+内心独白"** → 直接写动作，让读者自己体会
2. **"在月光/阳光/灯光下，他/她的脸/身影+形容词"** → 太套路，换个角度写
3. **"此时此刻，他/她终于明白..."** → 不需要总结式顿悟，用行为展现
4. **"空气中弥漫着...的气息"** → 具体写出什么味道
5. **"时间仿佛静止了"** → 被用烂了，换表达
6. **"一阵寒意/暖意涌上心头"** → 写具体的身体反应
7. **排比三连以上** → 最多两个，第三个必须打破
8. **每段结尾升华/总结** → 大多数段落应该自然结束
