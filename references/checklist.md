# 自检清单​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

## 一、快速检查（交付前逐条过）​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

- [ ] 连续三个句子长度相同？→ 打断其中一个
- [ ] 段落以简洁单行结尾？→ 变换结尾方式
- [ ] 揭示前有破折号？→ 删掉（对话打断除外）
- [ ] 解释隐喻或比喻？→ 相信读者能理解
- [ ] 使用“此外”“然而”等连接词？→ 考虑删除
- [ ] 三段式列举？→ 改为两项或四项（事实性三项除外）
- [ ] 一级禁词有命中？→ 必须改
- [ ] 二级禁词超过1次？→ 改到最多1次
- [ ] 段尾有总结升华？→ 删掉
- [ ] 情感有直说？→ 改为行为/细节

---

## 二、AIGC 8 维度自检（提示词版，不依赖脚本）​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

### 维度1：词汇多样性​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

- [ ] 同一事物是否反复用同一个词指代？（除人名外）
- [ ] 是否出现 3 次以上相同名词/动词？
- [ ] 有没有引入口语词、方言词、行业术语增加独特词？

### 维度2：句长波动​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

- [ ] 是否存在连续 3 个以上长度相近的句子？
- [ ] 每段是否至少有一个 3 字以内的短句和一个 20 字以上的长句？
- [ ] 关键节奏点是否用了极短句甚至单字成句？

### 维度3：短语重复​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

- [ ] 高频短语（“冷冷地看着”“不由得一愣”）全文是否超过 2 次？
- [ ] 动作描写是否有“副词+动词”固定搭配？
- [ ] 感官描写是否用了通用搭配（“深吸一口气”“眉头紧锁”）？

### 维度4：模板化表达​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

- [ ] 是否使用了“心中涌起”“不由得”“竟然”“仿佛”？
- [ ] 情感是否用了通用表达而非具体行为？
- [ ] 比喻是否用了常见喻体（“像刀割一样”“像坠入深渊”）？
- [ ] 这段话会不会出现在任何其他文章里？会 = 太模板

### 维度5：标点节奏​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

- [ ] 标点分布是否整段均匀无变化？
- [ ] 对话中是否允许省略号、破折号、句号交替？
- [ ] 有没有用句号密集制造停顿感？

### 维度6：对话比例​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

- [ ] 对话占比是否在 5%—65% 合理区间？

> 诊断参考区间 5%–65%；若被创作 skill（百万字小说生成）调用，以创作 skill 的 8%–55% 为准（guard.py 门槛）。

- [ ] 对话中是否穿插动作和细节？
- [ ] 关键信息是否用“话里有话”而非直说？

### 维度7：情绪/感官词密度​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

- [ ] 情绪词是否连续出现？
- [ ] 一个场景是否五感全上？（应重点写 1—2 种）
- [ ] 最强情绪是否用了最少的情绪词？

### 维度8：语义平滑度​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

- [ ] 段落间是否每段都紧密衔接、像流水账？
- [ ] 叙述中是否有看似无关的细节？
- [ ] 角色思维是否有跑偏和拉回？
- [ ] 段落结尾是否总和下段开头逻辑衔接？

## 三、可客观检查的硬项​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

以下项必须通过，不通过必须改：

- [ ] 一级禁词零命中
- [ ] 连续三句同长零出现
- [ ] 三段式强行列举零出现（事实性三项除外）
- [ ] 解释性破折号零出现
- [ ] “不仅是……而是……”零出现
- [ ] “作为……的证明/体现”零出现
- [ ] 协作交流痕迹零出现（“希望这对您有帮助”等）

## 四、文体附加检查​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

### 学术/法律/公关​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

- [ ] 没有第一人称
- [ ] 没有口语化
- [ ] 没有表情符号
- [ ] 术语完整保留

### 商业/营销​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

- [ ] 卖点保留
- [ ] 没有夸大宣传语
- [ ] 没有“通用积极结论”

### 小说/叙事​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

- [ ] 情绪藏于动作
- [ ] 有留白
- [ ] 有至少一处废笔
- [ ] 对话有信息差
- [ ] 结尾没有强行点题
