# 人类质感弥补方案​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

针对AI小说与人类小说的三层差距，制定具体可执行的写作规则。每条规则必须能在写作时对照执行，不是理论指导。

---

## 第一层：经验性差距的弥补​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

### G1 质感注入——强制每个场景至少一个"非平均细节"​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

**问题**：AI写的细节是"所有同类事物的平均值"，正确但空洞
**方案**：每写一个场景/物品/人物，必须注入至少一个具体的、非普遍的、有来源的细节

**规则**：
1. 写食物时，不要只写色香味，写一个不完美的细节——碗边溢出的汤汁、咬到砂子的瞬间、凉了之后表面凝的那层膜
2. 写天气时，不要只写"阳光明媚"，写阳光打在什么具体的东西上造成什么具体的效果——电线杆影子切过半截墙皮
3. 写人物外貌时，不要写"眉清目秀"，写一个辨识度高的不完美——左眉尾淡了一截、笑起来右眼比左眼小、指甲剪得很秃
4. 写空间时，不要只写大小和陈设，写一样不该出现在那里的东西——客厅角落的单只拖鞋、书架上倒插的一本书

**自检**：每写完一个场景，扫一遍：有没有至少一个细节是你不会在百度百科词条里看到的？没有就补。

**反面教材**：
> 她端来一碗热气腾腾的面，汤色浓郁，面条筋道，上面撒着翠绿的葱花。

**正面教材**（猫腻风格）：
> 面搁在桌上，碗底磕出一条细纹，葱花漂了半边，汤面上的油星聚成一个不太圆的圈。他没动筷子，先喝了一口汤，烫得舌头发麻。

**关键**：细节的质感来自"不完美"和"不均匀"。平均的、均衡的、完整的描写 = AI味。

---

### G2 情感矛盾——禁止纯情绪，必须加矛盾底色​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

**问题**：AI的情感是"干净"的，该悲伤就悲伤、该愤怒就愤怒。真实情感总是杂色的。
**方案**：每写一个情绪场景，必须叠加至少一层矛盾情绪或反常反应

**规则**：
1. 悲伤场景中，人物可以突然笑、可以注意到无关的细节、可以感到一丝轻松（终于不用装了）
2. 愤怒场景中，人物可以沉默、可以笑、可以突然觉得很累
3. 喜悦场景中，人物可以感到一丝不安、可以想起不好的回忆、可以刻意压住喜悦怕招忌
4. 释然场景中，人物可以突然哭——不是因为悲伤，是因为绷了太久的弦松了
5. **绝对禁止**："他心中涌起一股XX感"这类纯情绪直出。用行为、用反常反应、用生理反应代替

**情绪表达优先级**（从高到低）：
1. 矛盾行为（悲伤时笑、愤怒时沉默）
2. 生理反应（手抖、嗓子发紧、胃里翻涌）
3. 微小动作（抿嘴、移开视线、手指蜷缩）
4. 间接传达（旁人的反应、环境的变化）
5. 最末选：直接描述情绪（仅在其他方式都不适合时使用）

---

### G3 刻意不完美——有策略地写"坏"​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

**问题**：AI永远在写"好"的句子，结果整篇文章反而平庸。好作家知道什么时候该写碎句、该写不完整的比喻、该写不舒服的描写。
**方案**：在关键节奏点上，刻意打破行文流畅性

**规则**：
1. **冲击时刻**：用独立成段的极短句，甚至一个词。不要修饰，不要解释。
   > 他死了。
   > 就这么死了。
2. **情绪爆发**：允许句子破碎、省略主语、语法不完整。
   > 不可能。怎么会。站在那里。雨从领口灌进去。
3. **沉默/空白**：用环境声代替叙述，让读者自己填。
   > 很久没人说话。窗外有鸟叫，然后也没有了。
4. **不完整的比喻**：喻体只给一半，让读者自己补。
   > 她的笑容像——他没来得及想好那个比喻。
5. **突兀切换**：情绪最高点时切断，跳到下一个场景。不要收尾，不要过渡。

**反规则**：这些"坏"只在关键节奏点使用。日常叙事仍然要保持流畅。全篇都碎 = 另一种AI味。

## 第二层：技巧性差距的弥补​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

### G4 对话降功能——人物不是在传递信息，是在交锋​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

**问题**：AI的角色说话是为了推动情节，每句对话都有明确功能。真实对话充满废话、错位和言外之意。
**方案**：严格执行对话三层结构

**对话三层**：
1. **表层**：人物说的字面内容（可以是废话、套话、谎话）
2. **里层**：人物真正想表达或想隐藏的东西
3. **交互层**：两个角色的表层和里层之间的错位、误解、试探

**规则**：
1. 每段对话中，至少30%的内容不直接推动情节——可以是闲扯、跑题、答非所问
2. 两个角色对话时，至少有一处"信息差"——A知道的B不知道，或A以为B知道的其实B不知道
3. 重要信息不要通过对话直出，用"话里有话"的方式间接传达
4. 角色不会完美理解对方的意思——允许误解、过度解读、选择性忽略
5. 沉默也是一种对话——"我没说话"比"我同意"信息量大得多

**反面教材**：
> "我查到了，张三是凶手，他在案发当晚去了现场。"
> "你说得对，我们也发现了他的不在场证明是伪造的。"

**正面教材**：
> "你去过那条巷子？"
> 他没回答，把烟掐灭了。
> "我问你话呢。"
> "你问的哪句？"

### G5 人物有逻辑的矛盾——每个角色一个"反常区"​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

**问题**：AI的人物要么太一致，要么突变。人类角色有稳定的矛盾——勇敢的人怕蟑螂、吝啬的人对特定人大方。
**方案**：在角色卡阶段，为每个角色设定"反常区"

**规则**：
1. 每个主要角色必须有一个"反常区"——一个与其核心性格矛盾但稳定的特征
   - 冷酷的人对流浪猫心软
   - 大大咧咧的人对某件小事极度敏感
   - 胆小的人在某个特定领域异常勇敢
2. 反常区不是随机的，要有来源——过去的经历、重要的人、某次创伤
3. 反常区在故事中至少触发一次，且触发时角色的反应要不同于常态
4. 次要角色可以只展示一面，但主要角色必须展示矛盾

**自检**：写完角色卡后，问自己：如果删掉这个角色的名字，能不能从行为模式认出他？不能 = 角色太平。

---

### G6 伏笔自然化——撒种子而不是打勾​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

**问题**：AI的伏笔太工整，因果链太清晰，像是在完成清单。人类作家的伏笔更自然，有的发芽有的不发芽。
**方案**：区分"硬伏笔"和"软伏笔"，执行不同的埋设和回收策略

**规则**：
1. **硬伏笔**（必须回收的）：在关键节点埋设，埋设时让读者不觉得是伏笔——把它藏在日常叙事里，不要用暗示性语言引起注意
2. **软伏笔**（可回收可不回收的）：像撒种子一样散落在文中，回收了是惊喜，没回收也不影响——比如路边摊贩说的一句闲话、墙上一张过期的告示
3. **假伏笔**（误导性的）：故意让读者以为是伏笔，结果不是——或者回收方向与读者预期相反
4. 伏笔埋设时禁止使用"暗示性标记"——不要特意强调、不要用"他没注意到""谁也没想到"这类预示性语言
5. 回收时不要太干净——留一点余味，不要把因果链解释得滴水不漏

**自检**：回读埋伏笔的段落，如果读者第二次读才能发现这是伏笔 = 合格。第一次读就觉得"这里有问题" = 太刻意。

---

### G7 补充：快慢节奏判断标准

"快节奏"不是"段落短、句子短"，而是"信息密度高、动作连续"。
- 判定标准：读者是否被连续事件推着走，不喘气？是→快节奏；否→慢节奏。
- 市井喜剧的开场通常是**慢节奏**，允许长句铺陈，段落可以较长。

### G7 节奏呼吸——给叙事装上变速器​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

**问题**：AI给每个场景差不多重的笔墨，没有快慢轻重。
**方案**：用字数和句式控制节奏，不同场景类型执行不同的节奏策略

**规则**：
1. **快节奏场景**（打斗、逃跑、危机、高潮）：
   - 段落短，每段1-3句
   - 句子短，主谓宾为主，砍修饰
   - 动词密集，名词精简
   - 不写心理活动，只写动作和结果
   - 可以一句话独立成段

2. **慢节奏场景**（日常、回忆、铺垫、情感）：
   - 段落长，允许大段铺陈
   - 句子可以长，修饰和比喻可以多
   - 感官细节丰富
   - 允许跑题、闲笔
   - 人物心理可以有，但要化在行为和环境里

3. **过渡场景**（时间跳跃、场景切换）：
   - 一句话或一段话带过
   - 不要交代太细，读者不需要知道中间每一天干了什么
   - "三个月后"比"三个月里他每天如何如何"好

4. **节奏变速的信号**：快→慢用一个感官细节刹车；慢→快用一个突发事件加速。不要无缝过渡。

---

### G8 留白——最重要的东西不写出来​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

**问题**：AI总想写满，每个情感都点明，每个转折都解释。
**方案**：在以下场景中强制留白

**必须留白的场景**：
1. **角色最痛的时刻**——不要写他在想什么，写他在做什么（可能是件无关的事），让读者自己感受到痛
2. **重要告白/告别**——不要把话说完整，最关键的那句话可以用沉默、用打断、用转身代替
3. **真相揭开的瞬间**——不要解释为什么，让读者从前后文自己拼出来
4. **角色做关键决定的时刻**——不要写内心挣扎的完整过程，写决定前最后一个无意义的动作（点烟、系鞋带、看窗外）
5. **死亡的瞬间**——不要写遗言和感悟，写一个停止的细节（手的温度、呼吸的间隔、某个不再变化的微小动作）

**留白自检**：写完一段情感浓烈的文字后，试着删掉最后一句。如果删掉后更有力 = 应该删。如果删掉后看不懂 = 保留。

## 第三层：生成性差距的弥补​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

### G9 写作意图标注——让每章摘要不仅记"发生了什么"，还记"作者为什么这样写"​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

**问题**：AI每次写新章节是"读"了前文然后续写，缺乏作者对自己文本的直觉把握。
**方案**：在章节摘要中增加"写作意图"字段

**规则**：每章摘要额外增加：
```markdown
**写作意图**：
- 本章核心目的：[推进X线 / 埋伏笔Y / 展示角色Z的另一面 / 制造转折]
- 为什么这样写开头：[承接上章悬念 / 切换节奏 / 制造反差]
- 为什么这样写结尾：[留悬念 / 制造落差 / 呼应前文]
- 本章刻意使用的技法：[如"用环境暗示心理""对话全程信息差""节奏从慢到快骤变"]
- 下章需要注意的承接点：[具体说哪个情绪/悬念/动作需要延续]
```

这样下一章动笔前，不仅知道"发生了什么"，还知道"上一章的作者意图是什么"，减少续写时的理解gap。

---

### G10 低概率注入——每章至少一个"意外选择"​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

**问题**：AI的生成本质是概率，高概率 = 最常见 = 最平庸。最好的段落往往是低概率选择。
**方案**：在关键创作节点，刻意选择低概率但合理的方向

**规则**：
1. **比喻选择**：写出第一个比喻后，再想两个更不常见的，从中选最不常见但不违道的那个
2. **转折方向**：情节走到岔路口时，不要选最"合理"的方向，选"意料之外情理之中"的方向——如果两条路都合理，走人少的那条
3. **视角选择**：常规场景试试用非主角视角写——旁观者、对手、甚至无生命物体的视角
4. **情绪走向**：读者期待悲伤时给一丝暖，期待爽快时给一记闷棍，期待温情时给一个现实打击
5. **开头方式**：不要从时间顺序开头，从中间切入、从结尾倒叙、从无关细节开始

**自检**：每章写完后，找出本章最"意料之中"的段落，问自己：如果反着写，是不是更有力？如果是，改。

## 执行规则​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​

1. 以上10条规则编号G1-G10，在阶段4撰写时必须对照执行
2. 每章完成后，对照G1-G10逐条自检，标注"已执行/未执行/部分执行"
3. 未执行的条目必须补上（哪怕需要改写段落）
4. 这些规则与作家风格模仿并行不矛盾——G1-G10是底层质感规则，作家风格是表层风格规则，两者叠加
5. 持续进化机制（阶段6）中，G1-G10的执行情况纳入进化档案——哪些规则经常被遗漏，哪些规则效果最显著
